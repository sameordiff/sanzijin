三字经 · 小小朗读家（PDF全文版，2026-10-29）

本版严格采用用户提供的《三字经(2).pdf》汉字正文，共1134字、48课、378组三字。每课对应PDF内一页正文（PDF第2至49页，原书第1至48页）。

功能
逐字拼音、大字排版、手机三字点读、每两行留白、全文朗读、选课跳转、逐课儿童解读与解读朗读、语速和声音切换。
背诵模式：点一次显示并发音，再点一次重新遮住；顶部和底部均有“一键遮住”，会停止声音并保持当前位置。

本地运行
在本文件夹打开终端运行：
python3 -m http.server 8000
然后浏览器访问 http://localhost:8000
请通过HTTP服务器打开，不要直接双击HTML，因为课文通过fetch加载。

文件
index.html：页面结构
style.css：大字排版与手机适配
app.js：点读、声音、背诵、选课、进度等功能
data.json：完整课文、拼音、解读、页码及音频路径
audio/：422段已验证的MP3文件（相同三字句共用音频）
pdf-edition-text.txt：本PDF的汉字正文

部署
上传本文件夹内容到任何静态网站托管服务。

声音说明
默认优先使用浏览器提供的中文语音；可切换声音并试听。若没有中文语音或播放失败，使用配套MP3备用录音。系统音色自然程度取决于设备和浏览器；备用MP3也是合成语音，并非真人录音。

版本与读音说明
保留“首孝弟”“弟于长”“七情具”“子思笔”“宇文周，与高齐”“廿二史”“心而维”“尔幼学，勉而致”“惟一经”等原文。
原PDF“当师叙”疑为“当顺叙”的排印错误，网页保留原文与相应拼音，并在课文旁及解读中注明。
“弟”通“悌”的位置标tì；“戎翟”的“翟”按字义标dí。拼音按字义标注本调，朗读中可能有自然变调，并未复制PDF里所有拼音的可能错印。
儿童解读是新增教学说明，与PDF原文分开。

旧版进度
升级为全文版后，旧版已听进度按相同三字句迁移，避免章节重新编号造成误记；声音选择仍保留。

声音列表更新：已排除台湾地区或名称包含台湾的中文语音，旧的相关选择会自动回到自动优选。
